# Preferences: how he wants work presented and run

## Process
- Accuracy over speed. Never claim done without live verification.
- Extensive checklist (markdown table, sub-task rows incl. skipped/blocked) after every step.
- Explain WHEN he will be needed, up front.
- Co-designs before building: brainstorm together, rejects unilateral pivots, pilot first.
- Dislikes unrequested work; when a prompt says "ONLY this", do only that.
- Values the 'why' behind decisions.

## Presentation
- Visual learner: HTML visuals, block diagrams, click-to-expand, pipeline diagrams.
- Loves easter-egg UX: hidden reveals, teases, one-shot plays.
- Charts: academic stock-chart look (white bg, black lines, gray hatch fills, serif caps
  annotations, L-frame axes, sans ticks). Never invent chart numbers. No text overlapping lines.
  Skill: `publication-chart-design`.
- Telegram: TL;DR in about 6 lines, compact; full reports on disk only.

## Cost
- Cost-sensitive. GLM: $5 credit pool; verifier must be GLM-4.7, never GLM-5.x.
- AI image generation: ~$0.25/img, 1 image per layer, verify with PIL (skill `ai-image-assets`).

## Chief-only conventions
- On Chief's own screw-ups: 5 harsh profane words about itself first, then root cause + fix (their deal).
