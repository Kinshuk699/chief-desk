# Access routes: how to reach sources that "won't load"

Diagnosed by Chief, 2026-10-23. Every route is a public, official or archival copy. None evades a block.
Rule: a site "not loading" is a symptom; find the cause (wrong hostname, dead server, moved host) and the
legitimate route to the same document. Tool: `python3 ~/ChiefDesk/tools/gov_sources.py` (run with no args for help).

## Diagnose in 3 steps (2 minutes)
1. `dig +short <host>` then `curl -4 -s -o /dev/null -m 12 -w '%{http_code}' https://<host>/`.
   Timeout before TLS = server or route dead, not a bot block. 403/503 with a page = filtering.
2. Try the `www.` / bare-domain twin. Different IPs often mean one is on a CDN and works.
3. Is it dead for everyone? Try another network (the cloud browser in browser_exec), or check-host.net.
